# Demo Video Post

An empty shelf loses a sale. An overstocked shelf ties up money. Neither should come as a surprise.

A few days ago, I shared SME Retail Intelligence. Here is a closer look at how it works.

I built it for small shops that track sales in spreadsheets but do not have Shopify, an ERP, or a dedicated data team.

The starting point is simple: a CSV file.

From there, the full application helps shop owners:

* Import sales and inventory with row validation and duplicate protection
* See stock levels and identify fast and slow moving products
* Spot low stock and overstock risks
* Generate demand forecasts for the next 7 to 30 days, with error metrics to assess the results
* Ask inventory questions through an assistant backed by restricted, read only queries
* Give staff a separate workspace for imports and administration

The aim is not another dashboard to check. It is a clearer answer to what needs attention and what might need reordering.

This 58 second video shows the full application running locally with Docker and fictional shop data.
